# World's Hardest Game – Level Editor (Base)

Este repositorio contiene la estructura inicial de un editor de niveles para un juego estilo "World's Hardest Game".

Los módulos están vacíos con ganchos comentados para que puedas pegar la lógica más adelante.

## Estructura

- public/index.html — HTML del editor
- src/main.js — Inicializador
- src/styles.css — Estilos
- src/modules/ — Módulos JS vacíos
- levels/ — Ejemplo de nivel JSON
- docs/ — Documentación técnica
- .gitignore — Configuración básica

## Cómo ejecutar

```bash
cd public
python -m http.server 8000
```
